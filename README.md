# EQLibre

This repository is the central index for equalizer presets, Easy Effects profiles, and audio tuning references.

This README acts as the main map of the project. It does not contain generic or device-specific configuration details. For that information, refer to the corresponding documentation file.

## Main documentation map

### Generic reference
- [generic/generic.md](generic/generic.md) — generic presets and reference values.

### Device-specific references
- [devices/QCY-T13 ANC/QCY-T13 ANC.md](devices/QCY-T13%20ANC/QCY-T13%20ANC.md) — QCY T13 ANC device profile.

## Project structure

- [generic/](generic/) — generic profiles and shared references.
- [devices/](devices/) — device-specific documentation and presets.

## How to use this repository

1. Start from this file to navigate the project.
2. Read the generic documentation in [generic/generic.md](generic/generic.md) for shared presets and baseline values.
3. Read the device documentation in the relevant file under [devices/](devices/) when a model-specific profile is needed.
4. Import the corresponding JSON preset into Easy Effects or your preferred equalizer tool.

## Notes

- The project is organized by reference type: generic and device-specific.
- Documentation is kept in dedicated markdown files so the main README remains a clean navigation index.
- Full preset details, tables, and values are stored in the linked documentation files rather than in this file.
