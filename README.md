# EQLibre

EQLibre is a collection of equalizer presets and Easy Effects profiles intended as a practical reference for audio tuning and headphone configuration.

The project is organized to help users compare generic tuning profiles and device-specific settings in a simple and reusable way.

> Disclaimer: These presets are provided as reference configurations for experimentation and personal listening. They are not guaranteed to match every device, environment, or personal preference. Adjust values according to your equipment and listening taste.
