# Generic presets

This page contains the generic reference presets for EQLibre. These profiles are not tied to a specific device and can be used as a starting point for headphones, speakers, and other audio outputs.

The goal is to keep a clean set of generic tuning values that can be reused, compared, and adjusted according to room acoustics, hardware, and personal preference.

> Disclaimer: These presets are provided as reference configurations for experimentation and personal listening. They are not guaranteed to fit every device or environment. Adjust the values according to your equipment and listening taste.
